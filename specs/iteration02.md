#### Bugs

Поле "Матросы: [ ЧИСЛО ]" снабжено, через перенос на новую строку примиской "Максимум матросов: <число>", хотя должно выглядеть как "Матросы: [ ЧИСЛО ] / <число>"

При уменьшении количества матросов меньше половины, дробного изменения скорости в поле "Скорость, секторов/вахту" не происходит, а цифра числа матросов не меняе цвет на красный.

Отсутствуют поля "Смута", "Трюм", "Экипаж" – видны только заголовки.

Текст цифровых в полях "Прочность", "Трюм, стаунтов" вытянут по вертикали, с переносами строки – например "0\n / \n 1600", хотя должен быть в одну строку. В целом, все поля этого блока слишком большие – можно все их уместить одной строкой по горизонтали.

При снятии галочки в чекбоксе "Иллюминация" подсказка об иллюминации не пропадает. Верочем, этак подкащка как строка на листе и не нужна – пусть появляется только при наведении на пустой чекбокс "Иллюминация"

Блок с надписью "Бонус трюма при достоинстве «Вместительный трюм», ст. [  ]" стоит добавлять только при выборе достоинства "Вместительный трюм" и, с новой строки под блоком "Трюм".
